# Atlanta VPN — партнёрский сайт

Готовый статический сайт для размещения на обычном хостинге/Vercel/Netlify/GitHub Pages.

## Перед публикацией
1. Замените `https://YOUR-DOMAIN.ru` на ваш реальный домен в:
   - `index.html`
   - `sitemap.xml`
   - `robots.txt`
   - остальных HTML-файлах
2. Партнёрская ссылка уже установлена во все CTA:
   https://t.me/AtlantaVPN_bot?start=partner_6Lpp0Y
3. Проверьте условия партнёрской программы Atlanta VPN перед рекламой.
4. После публикации добавьте сайт в Google Search Console и Яндекс Вебмастер и отправьте `/sitemap.xml`.

## SEO
Есть title/description, canonical, Open Graph, Schema.org, robots.txt, sitemap.xml, отдельные тематические страницы и FAQ.

## Важно
Сайт прямо обозначает себя как партнёрский, а не официальный. Цены и технические условия рекомендуется проверять в боте перед покупкой.
