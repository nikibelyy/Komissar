# Расписание — PWA

Готовый фронтенд без backend-зависимостей.

## Запуск
Для PWA нужен HTTP(S), а не `file://`.

```bash
python3 -m http.server 8080
```

Открой `http://localhost:8080`.

## Возможности
- адаптивный UI для телефона/планшета/десктопа;
- добавление и удаление занятий;
- сохранение в localStorage;
- PWA manifest + service worker;
- автономное открытие после первого запуска;
- публичная ссылка через данные в URL hash — получатель видит то же расписание без аккаунта;
- анимации и UI в духе современных финтех-приложений.

## Важно
Это frontend-MVP. Если нужна настоящая публичная база расписаний, авторизация, короткие ссылки, QR-коды и синхронизация между устройствами, нужен backend (например Supabase/Firebase/свой API).
